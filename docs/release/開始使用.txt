Doujin Tagger（私藏編目室）Windows 版
=======================================

一般使用
--------

1. 將 ZIP 完整解壓縮到一般資料夾。
2. 雙擊「私藏編目室.exe」。
3. 第一次啟動時，選擇建立新的 catalog 或開啟既有 v2 catalog。
4. 在瀏覽器導引中設定新收藏資料夾、典藏庫資料夾與閱讀方式。
5. 完成首次掃描後即可使用。

不要把程式留在 ZIP 內直接執行。三個 EXE 必須放在同一資料夾。

日常使用只需雙擊「私藏編目室.exe」。若本機服務已在執行，程式會直接開啟既有 UI，不會重複啟動第二份服務。

疑難排解
--------

- 啟動錯誤會以 Windows 對話框顯示。
- 詳細記錄位於目前使用者的 LOCALAPPDATA 下之「Doujin Tagger」資料夾。
- 「doujin-launcher.exe」提供進階的 status、restart 與 stop 指令；一般使用不需要執行它。
- 本版本尚未進行程式碼簽章。Windows SmartScreen 若顯示警告，請先確認檔案是從本專案 GitHub Releases 下載，並可使用同頁提供的 SHA-256 核對。
