Doujin Tagger（私藏編目室）Windows 版
=======================================

安裝版（推薦）
--------------

1. 下載「私藏編目室_<版本>_x64-setup.exe」。
2. 雙擊執行安裝精靈：採「目前使用者」安裝，不需要系統管理員權限；若系統尚未安裝 WebView2，安裝程式會自動下載並安裝。
3. 安裝完成後，從開始功能表或桌面捷徑開啟「私藏編目室」。
4. 第一次啟動時，以原生對話框選擇建立新的 catalog 或開啟既有 v2 catalog。
5. 在程式視窗內的導引中設定新收藏資料夾、典藏庫資料夾與閱讀方式。
6. 完成首次掃描後即可使用。

安裝版是原生視窗程式，開啟後不會另外開啟瀏覽器分頁。關閉視窗即完全結束程式，不會留下背景服務。

若先前使用過免安裝版，安裝版會沿用同一份 catalog 選擇，不需要重新設定。

免安裝版（portable）
--------------------

1. 將 ZIP 完整解壓縮到一般資料夾。
2. 雙擊「私藏編目室.exe」。
3. 第一次啟動時，選擇建立新的 catalog 或開啟既有 v2 catalog。
4. 在瀏覽器導引中設定新收藏資料夾、典藏庫資料夾與閱讀方式。
5. 完成首次掃描後即可使用。

不要把程式留在 ZIP 內直接執行。三個 EXE 必須放在同一資料夾。

日常使用只需雙擊「私藏編目室.exe」。若本機服務已在執行，程式會直接開啟既有 UI，不會重複啟動第二份服務。

疑難排解
--------

- 啟動錯誤會以 Windows 對話框顯示。
- 詳細記錄位於目前使用者的 LOCALAPPDATA 下之「Doujin Tagger」資料夾；安裝版與免安裝版共用同一個記錄位置。
- 「doujin-launcher.exe」（僅免安裝版隨附）提供進階的 status、restart 與 stop 指令；一般使用不需要執行它。
- 本版本尚未進行程式碼簽章。Windows SmartScreen 若顯示警告，或部分防毒軟體（如卡巴斯基）將其誤判為風險，請先確認檔案是從本專案 GitHub Releases 下載，並可使用同頁提供的 SHA-256 核對。
