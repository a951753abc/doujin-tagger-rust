# Handoff: 私藏編目室 UI/UX 重新設計（暖紙色編輯風）

## Overview
本設計是「私藏編目室」（doujin-tagger-rust 專案中 `doujin-http/static/` 的同人誌收藏管理 Web UI）的完整重新設計。目標：**每頁呈現更多書籍、同時封面夠大**，並將原本的淺色紙質介面升級為「暖紙色編輯風」——米白紙面、襯線標題、橘色 kicker、藏青主色，靈感來自書店電商的編輯式排版。

資訊架構由原本 4 個分頁（藏書／工作台／統計／設定）改為 5 個：

1. **書架**（新首頁）— 依脈絡分列的橫向書架：待整理提示列、最近加入、本週特輯（滿版藏青帶）、場次書架
2. **全部藏書** — 大封面網格（6 欄）＋右側常駐檢視欄＋批次操作列
3. **工作台** — 批次操作＋同名候選裁決（沿用既有流程）
4. **統計** — 大數字＋可點擊篩選的量條表
5. **設定** — 閱讀器／縮圖／資料夾來源

## About the Design Files
本資料夾內的檔案是 **HTML 設計參考稿（design reference）**，不是可直接上線的程式碼。任務是**在目標程式碼庫既有環境中重現這些設計**：目標環境為 `doujin-http/static/` 的 vanilla HTML + CSS + JS（`index.html` / `app.css` / `app.js`，無框架、無建置步驟）。請沿用既有的 API 契約、路由（hash routing）、鍵盤操作與 `app.js` 行為模式，只重寫版面與樣式層。

**如何看設計稿**：用瀏覽器打開 `重新設計.dc.html`（需網路載入字型與圖示）。這是一張設計畫布，包含多輪探索；**最終定案只有這些區塊**（頁內錨點）：

- `#3b` 書架（首頁）
- `#4a` 全部藏書、`#4b` 工作台、`#4c` 統計、`#4d` 設定、`#4e` 對話框

其餘（`#1a`–`#2e`、`#3a`）為早期探索方向，**請忽略**。

## Fidelity
**High-fidelity（高保真）**。顏色、字級、間距、圓角、陰影皆為最終值，請以像素級精度重現。唯一例外：設計稿中的「書封」是純 CSS 色塊佔位（帶書名文字的彩色矩形）；實作時一律替換為既有縮圖 API 回傳的真實封面圖（3:4，`object-fit: cover`）。

### 3. 工作台（`#4b`）
- 雙欄 1:1，中間 1px #e9e1d2 分隔。每欄：橘色編號小標（01 / 批次操作、02 / 身分裁決）＋襯線 23px 藏青標題＋說明。
- **批次清單**：白卡（1px #e9e1d2）內逐列：38×51 縮圖＋襯線書名＋「來源 · 檔名」11px（省略號）＋「移出」灰連結。
- **批次工具**：兩張白卡 — 加標籤（輸入＋藏青「加入」鈕）、寫入手動值（欄位 select＋輸入＋藏青「寫入」鈕）。
- **檔案操作**：米黃警示卡（#fbf6ec 底、#e9d9c4 框）＋「搬移至典藏庫」（框線）＋「刪除已選收藏」（紅字框線）。
- **操作結果**：標題＋摘要一行；列表為書名＋右側狀態（完成＝綠 #476451、未變更＝#8a8071、失敗＝紅）。
- **候選裁決**：白卡；卡頭＝TOMBSTONE 編號（橘 kicker）＋襯線檔名＋路徑＋右側「待裁決 N 筆」徽章（#f5e3c8/#8a6325）；每列候選＝68×91 縮圖＋CANDIDATE 編號與原因（橘 kicker）＋檔名＋路徑＋狀態徽章（待裁決＝黃、已確認同一收藏＝綠 #dfe8df/#476451）＋動作（標記為同一收藏＝藏青實底；執行合併預檢＝橘實底；排除這個候選＝紅字連結）。

### 4. 統計（`#4c`）
- 大數字帶：上下 1px #d9cfba 框線、三欄（欄間 1px hairline）：襯線 54px 藏青數字（缺少 metadata 用橘色）＋12px 灰標籤。
- 下方 3 欄網格、六張表（種類／常見原作／主要場次／常見作者／常見社團／標籤涵蓋）：襯線 16px 藏青表題；每列＝4px 高橘色量條（寬度按比例 8–52px）＋名稱（可點擊帶入篩選）＋右對齊數字（tabular-nums）；列間 1px #e9e1d2。

### 5. 設定（`#4d`）
- 左欄 460px「閱讀與縮圖」：標籤 12px/700 #6d6455；輸入框白底 1px #d9cfba 4px 圓角；「儲存設定」藏青實底鈕；下方灰色小字說明重建行為。
- 右欄「資料夾來源」：標頭右側「重新掃描」橘實底鈕；來源表（白卡內 grid 列）：名稱（襯線 14px）／路徑（12px #8a8071）／用途徽章（新收藏＝黃、典藏庫＝藏青淡底）／狀態（已啟用＝綠）／「停用」紅連結；停用列整列 55% 透明。「新增來源」白卡：橘 kicker＋名稱/路徑/用途/「登記」藏青鈕一列排開。

### 6. 對話框（`#4e`）
- 背景遮罩 `rgb(43 38 32 / 55%)`；對話框白底（#fffdf8）4px 圓角、大陰影、內距 22px；破壞性對話框頂端 4px 色條（刪除＝#a63b2f、預檢＝#8a6325）。
- 結構：英文小標 kicker（9px letter-spacing .16em）＋襯線 21px 藏青標題＋灰說明。
- **刪除**：radio 卡兩張（選中＝#d97b1f 框＋#fdf3e3 底）；永久刪除需輸入確認文字（沿用既有邏輯）；主鈕紅實底。
- **合併預檢**：#214 ←（橘箭頭）#931 身分對卡（#f7f3ec 底）；逐欄 radio 選保留值；確認文字輸入；「合併收藏身分」藏青實底，未完成前 disabled（45% 透明）。
- **修正 metadata**：欄位 select＋新值輸入；左下「清除這個手動值」紅連結；取消（框線）＋儲存（藏青實底）。
- 未重繪的既有對話框（搬移、最近開啟、鍵盤說明）依同樣 token 換膚即可。

## Interactions & Behavior
- 沿用 `app.js` 全部既有行為：hash 路由、搜尋與篩選參數、分頁（每頁 96）、選取只保留在當前頁、縮圖 lazy-load 與輪詢、evidence 載入、批次部分成功回報、toast、dialog focus 管理、鍵盤（/、J/K、?、Esc）。
- 新增：書架首頁的資料組裝（最近加入＝掃描時間排序；場次列＝top_event；特輯＝選定 parody）；「檢視全部 →」＝導向全部藏書並帶入對應篩選；常用篩選 chip 同理。
- 詳細檢視由「點列選取」改為「點封面選取」，右欄常駐更新；aria-current 標記選中封面。
- hover：封面上浮 `translateY(-2px)`＋陰影加深（120ms ease）；連結 hover 轉橘；按鈕 hover 加深 8%。focus-visible 用 2px #1f3a68 outline。
